# routeros_api_command (Data Source)
Runs an arbitrary, read-only RouterOS API command (a '.../print'-style command) against any menu path and returns its result. Use this to query things that don't have a dedicated typed data source yet, e.g. counting entries in an IPv6 firewall address-list.

## Example Usage
```terraform
# Count the entries of an IPv6 firewall address list.
data "routeros_api_command" "blocklist_size" {
  path  = "/ipv6/firewall/address-list"
  words = ["count-only", "?list=blocklist"]
}

output "blocklist_size" {
  value = data.routeros_api_command.blocklist_size.result[0]["ret"]
}

# Read the rows of a menu that has no typed data source yet.
data "routeros_api_command" "ospf_neighbors" {
  path = "/routing/ospf/neighbor"
}
```

## Schema

### Required

- `path` (String) RouterOS API menu path to run the command against, e.g. `/ipv6/firewall/address-list`. A trailing `/print` is accepted and stripped automatically, since the print command is always the one that gets executed.

### Optional

- `words` (List of String) Raw RouterOS API sentence words/arguments for the command, e.g. `["=count-only=", "?list=blocklist-ipv64-dshield1"]`. Words starting with `?` are treated as print filters (RouterOS 'where' clauses, e.g. `?list=blocklist-ipv64-dshield1`); all other words are passed as literal command arguments (a leading `=` is optional and is stripped if present, e.g. `=count-only=` and `count-only` are equivalent).

### Read-Only

- `id` (String) The ID of this resource.
- `result` (List of Map of String) The rows returned by the command, each as a map of RouterOS property name to string value. Commands that return a single value instead of rows (e.g. with `count-only`) yield a single map, typically containing a `ret` key with the value.
